4. ARCHITECTURE TECHNIQUE DÉTAILLÉE

4.1 Le Moteur (Le Service)

Fichier : app/Services/AirtelSmsService.php

Son rôle est d'agir comme traducteur entre l'application et l'API Airtel.

  • Authentification sécurisée (Gateway Airtel)
  • Formatage ECP (Enterprise Content Provider)
  • Protocoles HTTPS et Gestion des certificats
  • Normalisation : transforme 074... en 24174...

4.2 L'Adaptateur (Le Channel)

Fichier : app/Channels/SmsChannel.php

Son rôle est d'être le chef d'orchestre intégré à Laravel. Il permet d'utiliser le SMS aussi simplement que l'email via SmsChannel::class.

4.3 Le Pattern d'Implémentation

Toutes les notifications suivent ce modèle strict :

namespace App\Notifications;
use App\Channels\SmsChannel;
use App\Services\AirtelSmsService;

class ExempleNotification extends Notification
{
    public function via($notifiable)
    {
        return ['database', 'mail', SmsChannel::class];
    }

    public function toSms($notifiable)
    {
        try {
            $phone = $notifiable->telephone ?? $notifiable->personne?->contact;
            if (!$phone) return;

            $service = new AirtelSmsService();
            $service->send($phone, "Message DGTT");
        } catch (\Exception $e) {
            Log::error("SMS Error: " . $e->getMessage());
        }
    }
}

7. COMMENT INTÉGRER UN NOUVEAU SMS ?

Guide Développeur Rapide Suivez ces 3 étapes pour ajouter une notification SMS à n'importe quelle classe existante.

Étape 1 : Les Imports

Fichier cible : app/Notifications/VotreNotification.php

Ajoutez ces lignes en haut de votre fichier, sous le namespace :

use App\Channels\SmsChannel;
use App\Services\AirtelSmsService;
use Illuminate\Support\Facades\Log;

Étape 2 : Activation du Canal

Fichier cible : app/Notifications/VotreNotification.php

Ajoutez SmsChannel::class dans la méthode via() :

public function via($notifiable)
{
    return ['mail', 'database', SmsChannel::class];
}

Étape 3 : Le Modèle Standard

Fichier cible : app/Notifications/VotreNotification.php

Copiez-collez la méthode toSms() :

public function toSms($notifiable)
{
    try {
        // 1. Récupérer le téléphone
        $phone = $notifiable->telephone ?? $notifiable->personne?->contact;

        if (!$phone) return;

        // 2. Envoyer
        $service = new AirtelSmsService();
        $service->send($phone, "DGTT - Votre message ici.");

    } catch (\Exception $e) {
        Log::error("[SMS ERROR] " . $e->getMessage());
    }
}
